# ComfyUI APIワークフローJSONの置き場所

**通常はこのディレクトリを使う必要はない。** チャプター毎のワークフローは
`build_h3_workflow.py`で直接生成するのが既定の方法（ブラウザ不要、入力上限と
17k+5フレームグリッドをスクリプトが強制する）。SKILL.mdの
「APIワークフローJSONの準備 → 方法A」を参照。

方法B（フォールバック）としてComfyUIのUIから **Export (API)** した結果を
ここへ置くこともできる:

- `h3_i2v_api.json` — セリフのないチャプター用（first/last frame条件付け）
- `h3_r2v_api.json` — セリフのあるチャプター用（参照画像＋音声）

方法Bの既知の落とし穴（実測）:

- ブラウザセッションが必要。ヘッドレス環境では使えない（`ui2api.py`で変換するか方法Aを使う）。
- **I2Vテンプレートはサブグラフ（UUID型ノード）で包まれている**ため単純な変換では展開できない。
- **公式テンプレートはテキストエンコーダにNVIDIA専用の`nvfp4_awq`をハードコードしている。**
  Blackwell以外では必ず差し替える。
- 解像度を`ResolutionSelector`（既定0.4MP）から取るので、`script.md`のフレーム数・
  解像度と食い違う。
